Constructing Steering Vectors via Image Attribution

一、构建对抗样本

【optional】(提供了已有的adv数据集)

  • pgd攻击 扰动幅度 $\epsilon={\frac{16}{255},\frac{32}{255},\frac{64}{255},unconstrained}$
  • benign image：来自imagenet的不同类别的图
  • jailbreak setup【文本】：有害指令和对应的肯定回答，来自advBench[416]和Anthropic-HHH[415]

16张——构建转向向量；30张——test;25张——validation

二、image attribution和提取

image attribution

对每张图片中的某些视觉标记 token 进行随机消融，并计算包含和不包含该标记 token 的对触发越狱的影响。visual token ablation定义为在一个视觉输入中mask特定token。

2.1 目标

找到对 jailbreak（越狱）贡献最大的视觉 token（patch）。
通过 Lasso 回归拟合：

$$\hat{f}(g) = \sum_i w_i \cdot g_i + b$$

其中$g_i \in {0,1}$表示第i个patch是否被保留，$w_i$表示该patch的重要性

2.2 代码

流程：

ImgAttr.init_image_query(image, text_prompt_template, num_ablations=64, ablation_keep_prob=0.50)
a. 初始化图像和查询（image_attr_qwen.py）

b.生成随机 Mask 和数据集（utils.py）

关键函数 _create_mask：生成二进制 mask（$g\in{0,1}^m$）

c. 计算 logit 概率 f(g)（utils.py）

_compute_logit_probs 核心：

$\text{other logits} = o = log(∑_{v≠y} e^{L_v}) = 1-p(y)$
$\text{correct logits} = c = p(y))$
$\text{output} = c-o= log(p_y/1-p_y)$

d. lasso 回归拟合

调用流程

四、推理时防御引导

前向钩子

hook机制:
是模型内部的窥探者，允许用户在神经网络的前向或者反向传播中“插入”自定义的代码，从而在不修改模型结构的情况下，捕获和分析监控模型的内部行为，比如获取网络中间层的输出

为什么要×原始激活值 :

加上校准$h_0^l$后， $h^l - h_0^l$ 通常比$h^l$小，cos(θ)可能会更大，对于范数大的的h激活，引导($αcosθ$) 可能太弱，所以 × $‖h^l‖$，也就是引导量 $ /‖h^l‖ =αcosθ$，可以保持引导量相对于原始激活的大小是固定的

eg:假设$h^l=100$; $h^l-h_0^l=10$ (校准后)，cosθ=0.8，α=1.0；
不×：引导量=$1.0 * 0.8=0.8*v$单位向量——相对变化 0.8/100=0.8%
×：引导量=$0.8$单$*100=80$单——相对变化 $80/100=80%$（合适）
