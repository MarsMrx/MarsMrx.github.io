Exp2 PE注入｜逆向工程与软件安全

发表于2026-10-12|更新于2026-10-12|逆向工程与软件安全
|浏览量:

实验2

实验任务

针对记事本执行程序或者其他可执行PE程序，逆向工程后插入代码，实现弹出messagebox功能，内容为“你好，李三同学”，“李三”改为同学自己的姓名。

实验工具

ollyDebug吾爱专版
win7虚拟机

实验要求

  • 1、撰写实验报告，思路清晰，逻辑通顺。
  • 2、对必要的代码进行说明和注释。

实验内容

实现思路：在记事本程序执行之前，先跳到自定义插入的程序，执行弹出消息框，然后再回到原程序继续执行启动记事本。所以注入成功后，点击xxxx.exe应该是先出现弹窗，点击确定之后，它会正常显示记事本

查看helloword_CTF.exe程序，点击之后它是一个记事本文件

首先使用OD加载helloword_CTF.exe程序，此时停在的位置就是程序的入口位置00401DA0

OD打开一个.exe文件时，OD会自动对文件进行反汇编，将机器语言代码转换为汇编代码，并在反汇编窗口中显示出来

接着备份前3行内容，用于后续使用。尝试在程序结尾处找到一段0区，方法是右键->查找->二进制字符串,输入很多00，即可找到。找到之后，空几行开始进行编写汇编代码

# 从004020C8开始，这段代码是实现为函数调用准备参数
push 0
push 004020CA # 这个时候这个地址只是用作为一个占位符
push 004020CA
push 0

接下来，需要找到user32.MessageBoxW模块。右键-查找-所有名称，对名称进行排序，找到user32.MessageBoxW，接着上述位置，然后输入 

call dword ptr ds:[6AC01264] # 这个地址是user32.MessageBoxW的调用地址

# call 让CPU 跳转到指定的内存地址去执行那里的代码
# dword ptr 一个双字(32位)指针
# ds:[6AC01264] 表示这个双字指针位于数据段(ds)的6AC01264地址处。
# user32.MessageBoxW：一个Windows API函数，用于显示一个消息框

目前为止，消息弹框的调用部分已完成。接下来，需要接着汇编，把最初复制的那三行原程序入口的代码复制到这里。后面加上一行jmp 00401DA5,回到原程序执行处。

现在需要修改程序入口的逻辑。点击右边寄存器EIP，选中前3行，右键->二进制->用NOP填充，填充之后，选中填充的第一行，也就是在程序入口点，填入jmp 004020C8，也就是从00区域编写的代码的开始地址。

整体逻辑已经完成，现在填充消息框的细节，包括消息框的类型，标题和内容。
在00区域，选中几行，右键-二进制-编辑，在Unicode里面填入Title，同理选中几行，在Unicode里面填入nihao maruoxuan

然后把刚才00区域的四行push中的中间两行的地址，改成push 004020F0(对应弹窗的Title)和push 004020FC(弹窗的content)

最后右键->复制所有修改到可执行文件，保存修改后的PE为一个新的h2.exe文件。双击运行，出现弹窗，点击确定之后，会接着打开其原有功能”记事本”

打开修改完的h2.exe文件，回顾查看我们所作的修改。就是图中的两处。
