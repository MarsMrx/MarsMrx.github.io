三、wireshark 802.11 PSK解密功能

❗在 Wireshark 中，PSK 指的是 Pre-Shared Key（预共享密钥），它是用于加密和解密 Wi-Fi 网络流量的密钥。具体来说，PSK 是 WPA（Wi-Fi Protected Access）或 WPA2 个人版（WPA-Personal）中使用的认证和加密机制的一部分
任务：分析一个包含「浏览器访问HTTP 明文通信网站的完整过程」的抓包结果文件；
SampleCaptures/wpa-Induction.pcap
SSID “Coherer”
password “Induction”

1. 确保有完整的4个eapol包

WPA（Wi-Fi Protected Access）和 WPA2 使用一种基于 EAPOL（Extensible Authentication Protocol over LAN）握手的密钥派生机制来加密 Wi-Fi 流量。Wireshark 需要捕获完整的四次握手数据包，才能使用 PSK 解密 Wi-Fi 流量。

2. 配置wireshark解密功能

在解密之前，Wireshark 只能显示加密的 Wi-Fi 流量（802.11 协议）

  • 配置psk解密，Edit->Preferences->Protocol->IEEE 802.11，点击edit添加密钥

  • 选择wpa-psk,输入密钥Induction：Coherer

  • 确定后，确保勾选Enable decryption 功能

3.解密后

在配置完成后，会发现pcap包里出现了其他协议的包，比如arp,tcp,http,icmp等，说明解密成功

2. SSID包含在哪些类型的802.11帧？

SSID理论上应包含在如下的帧里

  • Beacon Frame
  • Probe Request
  • Probe Response
  • Association Request
  • Reassociation Request

在该实验中(saved_01.cap)里，只有如下三个包有SSID

也可以通过新增一个frame type列，然后过滤器输入wlan.ssid统计哪些帧中包含SSID,结果是4，5，8，同上结果一致

3.扩展：如何分析出一个指定手机在抓包时间窗口内在手机端的无线网络列表可以看到哪些SSID？这台手机尝试连接了哪些SSID？最终加入了哪些SSID？

  • 可看到的SSID

    • 可以通过查看当前无线网络覆盖内的Beacon frame帧，或者查看该手机发送的所有Probe Request帧 在这些帧中,分析wlan.ssid 字段,即可看到手机扫描到的SSID列表

    • wlan.fc.type_subtype == 0x04 && wlan.sa == <手机MAC>

  • 尝试连接的SSID

    • 通过查看该手机发送的 authentication frame来查看，或者Association Request帧

    • wlan.fc.type_subtype == 0x00 && wlan.sa == <手机MAC>

  • 最终加入的SSID

    • 查看手机收到的Association Response帧判断最终加入了哪些SSID

    • wlan.fc.type_subtype == 0x01 && wlan.da == <手机MAC>

实验问题以及解决方法

  1. kali里终端的crtl c无法终止进程，原因是快捷键crtl c被设置成为复制的作用，冲突了。
    解决：为复制重新设置一个快捷键即可

  2. 无线网卡有时候无法识别或者抓不到包
    解决：

    • 更改虚拟机的usb控制器类型，符合usb网卡类型
    • 在虚拟机中点击挂载usb设备之后，需等待。若多次点击，会提醒无法挂载usb设备
    • 抓不到包，可以sudo airmon-ng check kill之后，重新进入监听模式
