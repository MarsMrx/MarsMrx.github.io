大川学堂助手（整合版）使用教程

一、脚本介绍

大川学堂助手是一个运行在浏览器 Tampermonkey（篡改猴）中的用户脚本，针对大川学堂（ecourse.scu.edu.cn）课程视频学习页，主要提供：

  • 防止鼠标离开网页暂停：伪造页面可见状态，拦截鼠标移出、窗口失焦等检测，实现视频后台持续播放。切换标签页或操作其他应用程序时，播放不受影响——即可切屏。
  • 自动续播课程视频；
  • 实现视频倍速播放；
  • 提供可拖拽、可折叠的倍速悬浮面板。

二、安装 Tampermonkey

Tampermonkey（篡改猴）是一款浏览器扩展，用来管理和运行用户脚本。

方式一：从浏览器插件中安装

  1. 打开 Edge/Chrome 加载项商店，搜索 Tampermonkey或”篡改猴“。（推荐chrome或者edge浏览器）
  2. 选择官方扩展，点击“获取”或“添加”。
  3. 确认添加。

方式二：官方github仓库下载
链接：Tampermonkey
安装完成后，浏览器右上角会出现 Tampermonkey 图标。

三、浏览器必要配置

不同浏览器对用户脚本有限制，请按下面进行配置。

Chrome / Edge

  1. 打开扩展管理页：

    • Chrome 地址栏输入 chrome://extensions/
    • Edge 地址栏输入 edge://extensions/

  2. 打开chrome右上角或Edge左下角的 开发者模式。

  3. 找到 Tampermonkey，点击“详情”。

  4. 确认：

    • 允许用户脚本：开启；

    • 站点访问权限：设为“在所有网站上”，或至少允许 ecourse.scu.edu.cn。

如果找不到“允许用户脚本”，请升级 Tampermonkey 和浏览器到较新版本。

四、把脚本加入 Tampermonkey

  1. 点击浏览器右上角 Tampermonkey 图标。
  2. 选择“添加新脚本”。
  3. 将“大川学堂助手（整合版）”的完整脚本内容粘贴到编辑区，覆盖原有默认代码。按 Ctrl + S 保存。
  4. 回到 Tampermonkey 脚本列表，确认插件和对应脚本前面的开关为开启状态。

或者点击链接直接安装脚本

五、在刷课时如何使用

  1. 登录大川学堂，我的学习-我的课程-公开课/其他等。打开左侧章节目录，点击任意视频小节进入播放页。
  2. 此时右上角的插件会显示出可用脚本，点击开启，button变成绿色，脚本名字变成黑色（非灰色），代表脚本成功启用。
  3. 如果脚本没有立即生效，刷新一次页面。
  4. 页面左下角（默认位置）会出现 ⚙️ 播放设置 悬浮面板：
    • 点击 1.0x、1.25x、1.5x 等按钮选择倍速；
    • 按住面板顶部标题栏可拖动位置；
    • 点击 ▲ / ▼ 可折叠或展开；
    • 倍速和面板位置会保存在当前浏览器，下次进入仍然生效。
  5. 视频会尝试自动播放。如未自动播放，手动点击一次播放按钮。
  6. 视频接近结束时，脚本会按左侧目录顺序自动播放下一小节。

建议倍速不要过高，1.5x–2.0x 较稳定。过高可能因网络或平台限制出现卡顿。

六、常见问题与不足

若插件和脚本未生效，请检查杀毒软件/安全软件是否拦截了浏览器扩展，可在软件中将浏览器加入信任列表。

问题 处理建议
页面提示“此脚本还未被执行” 确认脚本已启用；刷新页面；检查 Tampermonkey 权限
没有出现播放设置面板 确认已进入具体视频页；刷新页面；查看 Tampermonkey 图标是否有运行提示
视频没有自动播放 手动点一次播放；允许站点声音；刷新重试
自动播放没有声音 脚本自动播放默认静音，手动取消静音即可
没有自动下一课 展开左侧目录；确认当前小节高亮；手动点下一节验证；已是最后一节时不会自动跳转
倍速被改回 1.0 重新点击倍速按钮，脚本会尝试恢复
页面卡顿 降低倍速；关闭其他同类脚本；只保留一个播放页面

已知限制与使用建议

  • 进度同步提示：若长时间连续挂机（如超过 5 小时），可能出现部分小节已实际播放，但左侧目录进度圆圈未填满的情况。此时通常只需手动重新点击该小节即可完成进度同步。
  • 倍速建议：过高倍速（如 4x）可能触发平台检测机制，导致播放时长判定异常、学习记录无效。建议倍速控制在 1.5x–2.0x 范围内。
