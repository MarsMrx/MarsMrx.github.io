实验内容

固件：是嵌入在硬件设备中的软件，用于控制设备的基本功能。
通常存储在闪存芯片上，是设备运行所必需的。例如，路由器的固件包含了操作系统和网络设置等功能。

固件仿真：是一种技术，用于在虚拟环境中运行固件，而不需要实际的硬件设备。
通过仿真，可以分析固件的功能、安全性等特性。这对于固件研究、漏洞挖掘和逆向工程非常重要。

步骤一：使用基础工具分析固件

    binwalk 是一个强大的固件分析工具，用于扫描和提取固件中的文件和文件系统

  • 查看文件类型

  • 查看文件中的可打印字符

  • 查看字符串及其偏移量（十六进制）

  • binwalk扫描分析固件

    使用 binwalk 扫描固件文件，识别其中的文件系统、压缩文件等。显示固件中嵌入的文件系统、文件等信息。可以快速了解固件的结构，识别其中的文件系统和文件

思考题

  • firmwalker 的输出结果中，有哪些类型的敏感文件？

    • SSL/TLS证书相关文件
    • 配置文件
    • shell脚本文件
    • 密码相关文件
    • web服务器文件

  • 针对上述固件的 firmwalker 输出结果，任选三类敏感文件，每一类列出至少三个文件名

    1. SSL/TLS证书相关文件
      /etc/stunnel_cert.pem
      /etc/stunnel.key
      /etc/openssl.cnf
    2. 配置文件
      /etc/resolv.conf
      /etc/stunnel.conf
      /etc/udev/udev.conf
    3. Shell 脚本文件
      /htdocs/upnp/NOTIFY.WANIPConnection.1.sh
      /etc/init.d/S19init.sh
      /etc/events/DHCP4-RENEW.sh

  • 【扩展】请分析 firmwalker.sh 文件，回答以下问题：

    • firmwalker 工具是如何实现的？请给出其实现思路。
      该脚本用于遍历固件的文件系统，查找和分析文件。

      参数解析与初始化：检查用户输入的参数，设置固件目录路径和输出文件名。
      敏感文件搜索：通过预定义的文件名模式列表（如密码文件、SSL 相关文件、SSH 相关文件等），使用find命令在固件目录中递归查找匹配的文件。
      模式匹配与内容提取：对固件中的文件内容进行模式匹配，提取诸如 Unix-MD5 哈希、IP 地址、URL 和电子邮件等敏感信息。
      Web 服务器与重要二进制文件查找：查找与 Web 服务器相关文件和重要二进制文件，分析固件中可能的网络服务和关键程序。
      静态代码分析（可选）：通过集成的静态代码分析工具（如 eslint），对固件中的代码进行分析，查找潜在的安全问题。
      结果记录与报告生成：将所有搜索和分析结果记录到指定的输出文件中，以便后续审查。

    • 请任选两类敏感文件类型，找出 firmwalker.sh 工具中对应查找固件中对应类型的敏感文件的源代码，并逐行添加注释进行分析

      • 查找密码文件

      • 查找shell文件

问题与解决

  1. 使用binwalk进行固件提取时，出现警告，不过不影响正常的提取

    • 警告1：sasquatch 没有安装 ;Binwalk 想用 sasquatch 这个工具来提取 SquashFS 文件系统中的内容，但是缺少工具，安装即可
      sudo apt install sasquatch

    • 警告2：符号链接指向了目录外部，被重定向,市一种安全机制，不影响

  2. 使用firmwalker分析固件时遇到shodan init缺少密钥，卡住了无法接着分析

    解决方法：去官网注册并登录，获取api key
